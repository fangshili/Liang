# 测试脚本 · T3｜光晕渲染参数

运行方式：在 Xcode 中打开本文件夹的 `Package.swift` 点 Run，或终端执行 `swift run`。

步骤：
  1. 运行 App，确认刘海/顶部中央出现青色光晕。
  2. 点击菜单栏图标 → 设置，打开设置窗口。
  3. 拖动“亮度”滑块，确认光晕明暗实时变化。
  4. 拖动“模糊半径”滑块，确认光晕扩散范围实时变化。
  5. 拖动“厚度”滑块，确认光环粗细实时变化。
  6. 使用“颜色”拾色器换色，确认光晕颜色实时变化。
  7. 打开/关闭“呼吸效果”，确认光晕是否开始/停止呼吸。
  8. 拖动“呼吸速度”，确认呼吸节奏变化。
  9. 在系统设置中开启“减少动态效果”（辅助功能 → 显示），确认呼吸自动停止。
  10. 在系统设置中开启“低电量模式”，确认呼吸自动停止。
  11. 点击“恢复默认”，确认光晕回到初始青色呼吸状态。
  12. 关闭设置窗口后再次打开，确认滑块/开关状态保持。

预期：
  - 所有参数调整都能实时反映到光晕上。
  - 减少动态效果或低电量模式下，呼吸效果被禁用，光晕保持静态。
  - 设置窗口能反复打开/关闭。
  - 光晕不遮挡菜单栏点击。

性能：调整参数时光晕无卡顿，静态时无明显 CPU/GPU 占用。

判定：参数实时可控、系统约束正确响应 = 通过。

不通过怎么反馈：描述调整的参数、看到的现象，并附截图。

Liang 图标设计方案

Liang（亮）= 一本书写「光」的名字。App 常驻菜单栏，用围绕刘海/顶部的光晕提示 AI IDE 的工作状态。以下 8 款均围绕「光晕 / 亮光」主题设计，请挑选你心仪的款式。

idle #E58325 processing #00BFFF waiting #FFD700 success #00FF52 error #FF3B30
设计口径：菜单栏图标采用单色（template）画法——系统会自动适配浅色/深色菜单栏，且小尺寸下更清晰；真正的「彩色光晕」由 App 运行时的刘海光效承担（见上方状态色）。App 图标则使用满色 + 光晕渐变，在深色圆角底上让光更突出。每款下方两张菜单栏预览分别模拟浅色与深色系统菜单栏。

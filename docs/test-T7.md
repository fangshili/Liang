# T7 测试脚本：配置持久化与设置面板

## 目标

验证 Liang 设置面板的侧边栏布局、功能开关、各状态颜色配置和自动持久化均正常工作。

## 前置条件

1. 完成 T1–T6。
2. 已通过 `swift build`。
3. 已在菜单栏打开 Liang 并能看到设置窗口。

## 测试步骤

### 1. 打开设置面板

- 点击菜单栏 Liang 图标 → “设置…”。
- 期望：设置窗口正常弹出，左侧为侧边栏（通用、光晕、Cursor、状态颜色、高级、关于），右侧为内容区。

### 2. 切换功能开关

#### 2.1 关闭“启用光晕”

- 在「通用」页取消勾选“启用光晕”。
- 期望：刘海光晕立即隐藏；再次勾选后光晕恢复显示，并应用当前状态颜色。

#### 2.2 关闭“启用 Cursor Hooks”

- 在「通用」页取消勾选“启用 Cursor Hooks”。
- 期望：菜单栏状态变为“未连接”，Liang 不再接收 Cursor 事件；再次勾选后恢复监听。

### 3. 调整状态颜色

- 点击左侧「状态颜色」。
- 默认状态下颜色只读展示，点击右上角「编辑」进入编辑模式。
- 编辑模式下，点击某个状态的色盘即把光晕切换到该状态；调整颜色时光晕会即时跟随变化，不受 Cursor 当前任务影响。
- 逐个修改 idle / processing / waiting / success / error 的颜色。
- 点击「保存」退出编辑模式，光晕恢复跟随真实 Cursor 状态。
- 期望：
  - 默认颜色列表不可直接编辑。
  - 进入编辑模式后，点击哪个状态的色盘，光晕就切换成该状态并实时反映颜色变化。
  - 点击下一个状态的色盘时，光晕再次切换。
  - 点击「保存」后，光晕恢复为编辑前的真实状态；如有 Cursor 任务，则跟随 Cursor 任务。
  - 点击「重置默认颜色」后，所有状态颜色恢复为默认值。

### 4. 调整光晕与动画参数

- 点击左侧「光晕」。
- 拖动亮度、模糊半径、内外侧厚度等滑块。
- 修改“呼吸速度”或关闭“呼吸效果”。
- 期望：光晕实时响应参数变化。

### 5. 高级参数

- 点击左侧「高级」。
- 调整 Processing 超时、Success 保持时间、去重窗口，或开启 Waiting 超时。
- 期望：状态引擎行为按新参数生效；退出重启后保持。

### 6. 持久化验证

- 修改颜色、光晕参数、高级参数。
- 完全退出 Liang（Cmd+Q）。
- 重新运行 Liang。
- 期望：所有修改过的值恢复为上一次设置，而非默认值。

### 7. 恢复默认

- 在「通用」或「高级」页点击“恢复默认”。
- 期望：
  - 所有滑块回到默认值。
  - 状态颜色恢复为默认（idle `#E58325`、processing `#00BFFF` 等）。
  - 功能开关恢复为开启。
  - 退出并重启后仍保持默认值。

### 8. 复制当前配置

- 在「通用」页点击“复制当前配置”。
- 期望：剪贴板中包含当前所有配置项的文本，包括各状态颜色 hex 值和高级参数。

### 9. 损坏配置回退

- 手动写入一段非法 JSON 到 `defaults write liang settings.v1` 或直接修改 `~/Library/Preferences/liang.plist` 中的 `settings.v1` 键。
- 重新运行 Liang。
- 期望：Liang 不崩溃，日志输出“配置读取失败，使用默认值”，并使用内置默认配置。

## 通过标准

- [ ] 设置窗口正常显示，侧边栏可切换各页。
- [ ] 两个功能开关即时生效。
- [ ] 状态颜色修改即时生效。
- [ ] 光晕参数修改即时生效。
- [ ] 高级参数持久化并生效。
- [ ] 配置在退出后持久化。
- [ ] “恢复默认”正确重置并持久化。
- [ ] 配置损坏时安全回退到默认值。
- [ ] `swift build` 无错误。

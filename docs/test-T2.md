# 测试脚本 · T2｜屏幕几何探测和无交互光晕

运行方式：在 Xcode 中打开本文件夹的 `Package.swift` 点 Run，或终端执行 `swift run`。

步骤：
  1. 运行 App。
  2. 观察屏幕顶部刘海/菜单栏区域：
     - 有刘海设备：应看到青色光晕环绕刘海。
     - 无刘海设备：应看到屏幕顶部中央有一条青色圆角光晕。
  3. 点击菜单栏图标，确认仍能呼出菜单；点击菜单栏其他位置，确认光标和菜单交互正常。
  4. 调整显示器分辨率或缩放（系统设置 → 显示器），确认光晕重新定位到正确位置。
  5. 如有外接显示器，切换主屏或拔掉外接屏，确认光晕跟随主屏变化。
  6. 打开一个 App 进入全屏，观察光晕行为（T2 仅监听 Space 变化，全屏隐藏策略后续完善）。
  7. 点击“退出 Liang”，确认 App 退出。

预期：
  - 光晕出现在主屏刘海或顶部中央，位置大致正确。
  - 光晕窗口不拦截鼠标事件，菜单栏可正常点击。
  - 显示器参数变化后光晕能重新定位。
  - Dock 栏无 Liang 图标。

性能：光晕静态显示，无明显 CPU/GPU 占用。

判定：光晕可见、位置正确、不影响菜单操作 = 通过。

不通过怎么反馈：描述设备型号（是否有刘海）、光晕出现位置、最近一次操作，并附截图。
